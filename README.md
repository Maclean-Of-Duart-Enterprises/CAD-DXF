CAD DXF

CAD DXF is an open-source Android CAD application for viewing, creating, editing, measuring, and saving DXF drawings directly on your device.

The application provides an interactive CAD workspace with support for common drawing entities and editing operations, including lines, polylines, circles, arcs, ellipses, text, dimensions, hatches, layers, colors, lineweights, object selection, grip-point editing, move/offset operations, undo/redo, zoom, pan, object snapping, and drawing measurements.

Features

- Open and save ".dxf" files using Android's native file picker
- Create and modify CAD geometry
- Lines, polylines, circles, arcs, ellipses, text, dimensions, hatches, and other DXF entities
- Entity selection and grip-point editing
- Layer management
- Editable colors, linetypes, and lineweights
- Object snapping and precision drawing tools
- Distance, radius, arc-length, and other measurement tools
- Zoom, pan, fit-to-screen, and drawing navigation
- Undo and redo
- Blocks and attributes
- Paper-space/layout support
- Touch/mobile-oriented CAD controls
- High-performance rendering designed for large drawings
- Local DXF processing without requiring a CAD backend
- Android file integration for opening and exporting drawings

Privacy & Offline Use

DXF processing and rendering are performed locally by the application. A remote CAD conversion service is not required for normal DXF operation, making CAD DXF suitable for offline and privacy-sensitive workflows.
